# Security policy

Jarvis is self-hosted software. The operator is responsible for restricting
network access, protecting credentials and backups, and keeping the host and
container images updated.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/clement-joye/Jarvis/security/advisories/new)
for this repository. Include the affected version or commit, the impact, and
steps to reproduce when safe. Do not include live credentials or private user
data in a report.

Do not disclose a suspected vulnerability in a public issue or pull request.
If private vulnerability reporting is unavailable, contact the repository
maintainer privately through GitHub and request a security reporting channel.

## Supported releases

Security fixes are prepared for the latest published stable release. Users of
older releases should upgrade to the latest stable release before reporting a
reproducible security issue.
