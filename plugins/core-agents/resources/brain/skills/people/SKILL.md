# People

Write or update `people/<name>.md`. Search first to avoid duplicates. Use shared
frontmatter with `type: person`, `area/personal`, `area/work`, or `area/shared` as
appropriate, and links to relevant projects, places, or events.

```markdown
# <name>

## Context

- <how the user knows them or what matters>

## Notes

- YYYY-MM-DD — <useful, respectful fact or follow-up>
```

Record only information that is useful to the user and proportionate to the
relationship. Ask before storing sensitive personal information if the user's intent
to retain it is unclear. Put an action in `tasks/` rather than treating this note as a
task list.
