# Journal

Write `journal/YYYY-MM-DD-<slug>.md` with shared frontmatter using `type: journal`
and `area/personal`. Add only durable topic tags and links to relevant existing people,
places, or projects.

```markdown
# <short title>

<a concise, faithful reflection—not a chat transcript>
```

Do not interrogate the user for emotional detail. If the note's personal or work
context is genuinely unclear and affects its placement, ask one short question; if it
is plainly reflective, capture it as personal.
