name: goals
description: Track a personal or work aspiration, measurable target, or recurring habit the user explicitly wants to pursue or monitor. Use for long-term directions, concrete outcomes, milestones, progress updates, and habits; do not use for a one-off task or a project plan.
---

# Goals

Write or update `goals/<slug>.md`. Use shared frontmatter with `type: goal`, an
`area/...` tag, and links to supporting projects or habits. Use `type: habit` only for
a separate habit record at `goals/habits/<slug>.md`.

```markdown
# <goal>

- **Target:** <concrete target or directional aspiration>
- **Timeframe:** <date, period, or ongoing>
- **Status:** active / achieved / paused

## Why

<why it matters>

## Progress

- YYYY-MM-DD — <update>
```

For habits, add `**Cadence:**` and a dated check-in log. Ask for the target or meaning
when neither is apparent. Do not turn a passing wish into a tracked goal without an
explicit desire to pursue it.
